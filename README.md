# Portfolio – Gustavo Correia Dias

This project is a personal portfolio website developed to present my professional profile, experience, technical skills, and projects created throughout my career as a software developer.

The portfolio was designed to be modern, accessible, and responsive, allowing visitors to easily explore my work in a clear and objective way.

---

## 🎯 Project Purpose

- Present professional information in an organized and visually appealing way.
- Demonstrate frontend development skills.
- Serve as a digital business card for professional and academic opportunities.

---

## ⚙️ Features

- **Language selection:**  
  Users can switch between Portuguese (PT-BR) and English (EN).

- **Theme switching:**  
  Supports light mode and dark mode.

- **Responsive design:**  
  Layout adapts to desktops, tablets, and mobile devices.

---

## 🛠️ Technologies Used

- **React** – Library used to build the user interface.
- **TypeScript** – Language used to ensure static typing and better code reliability.
- **ReactBits** – Component library used in parts of the interface.
